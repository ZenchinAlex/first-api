# First API

Первое приложение на FastAPI: маленький сервер с тремя адресами (эндпоинтами).

## Адреса
- `GET /` — приветствие
- `GET /hello` — приветствие со своим текстом
- `GET /hello/{name}` — приветствие по имени из адреса (например, `/hello/Alex`)
- `/docs` — автоматическая документация, где адреса можно проверить мышкой

## Запуск
1. Установите Python 3.12
2. Скачайте проект:
```
git clone https://github.com/ZenchinAlex/first-api.git
cd first-api
```
3. Создайте виртуальное окружение и установите библиотеки (Windows, PowerShell):
```
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```
4. Запустите сервер:
```
fastapi dev main.py
```
5. Откройте в браузере `http://127.0.0.1:8000/docs`

## Пример
Запрос `GET /hello/Alex` вернёт:
```
{"message": "Привет, Alex!"}
```
Запрос к несуществующему адресу (например, `/bye`) вернёт код `404`:
```
{"detail": "Not Found"}
```
